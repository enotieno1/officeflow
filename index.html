Security & governance

Designed for accountable access

OfficeFlow is built around organisation-aware access and role-based permissions. Security claims below describe intended controls; production effectiveness still requires deployment and access-control testing.

Role-based access

Different role levels are intended to limit users to the functions and records relevant to their responsibilities.

Organisation separation

Tenant-aware data access is intended to keep each organisation's records separate. This must be validated with cross-organisation security tests.

Traceability

Workflow history and audit records support review of actions and approvals. Retention, completeness and access controls should be verified for the deployed environment.

Need a security review or deployment-specific details? Contact the OfficeFlow team.
