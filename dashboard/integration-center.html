Spreadsheets

Excel / Google Sheets

File tools available

The OfficeFlow spreadsheet workspace supports file import/export and is designed for cloud saving. That is not the same as live synchronisation with a user's Microsoft or Google account.

To enable live sync
  • Complete Microsoft Graph or Google Sheets OAuth
  • Define which workbook and spreadsheet actions are allowed
  • Implement sync conflict handling and audit records
  • Test read/write access with a real authorised account

What is still needed inside OfficeFlow

Provider credentials alone are not enough. The application needs secure backend callback routes, encrypted token storage, organisation-scoped access controls, refresh/revocation handling, sync logs, error reporting and verified tests. Do not put client secrets in frontend HTML or commit them to GitHub.
