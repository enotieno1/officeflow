LIVE SYNC NOT SET UP

OfficeFlow’s spreadsheet workspace supports file import/export. File handling does not mean that a user’s Microsoft or Google workbook is synchronised.

To enable live synchronisation

  • Complete Microsoft Graph or Google Sheets OAuth
  • Define permitted workbook and spreadsheet operations
  • Implement conflict handling and sync audit records
  • Test real read/write access with an authorised account
