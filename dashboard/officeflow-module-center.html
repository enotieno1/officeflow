Important implementation boundary

This workbench connects supported record actions to live tables. Secure file upload/storage, outbound email delivery, external AI-provider calls, recurring calendar reminders, automatic fraud detection, and billing activation require separate server-side integrations and end-to-end tests. They must not be represented as active until configured.
