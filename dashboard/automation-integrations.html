Document OCR & Capture

Upload a supported image, extract editable text in the browser, review the suggested folder and save the scan to the document register. The current scanner accepts JPG, PNG and WEBP images; PDF OCR is not yet confirmed.

Open Document Management → ⇢Admin access

Workflow Builder

Configure workflow owner, ordered approval steps, responsible units, approver roles and service-level deadlines. Publishing uses the existing workflow RPCs and must pass your organization's access rules.

Build a workflow → ϟRule engine

Workflow Automation

Create event-triggered rules for request creation, status changes, approval-step changes and overdue steps. Available actions include notifications, task creation, priority/SLA updates and email queueing.

Open Automation Engine → ✉Delivery provider unverified

Messaging & Communications

Open the communications workspace to manage departmental communication. Email/SMS/WhatsApp delivery requires a configured provider, server-side credentials, delivery callbacks and retry monitoring; a queued message is not a sent message.

Open Communications → ⌘Setup required

Payment & Provider Integrations
